# FORMA — Training Tracker

## Files
- `index.html` — complete workout tracker app.
- `manifest.webmanifest` — installable web app name, theme and icon metadata.
- `icon.svg` — FORMA app icon.

## Run
Open `index.html` in a modern browser, or serve this folder from a static web host.
For install prompts/PWA behavior, publish the folder over HTTPS. Workout data is stored
locally in the browser on each device; use the built-in Settings backup/export feature
to move or protect your training history.

## New: Your gym years
The Progress tab now includes a yearly training calendar. A day lights up when at least
one completed workout exists in the saved history for that local calendar date. The year
selector lets you review previous years; totals show active days, workouts and longest
consecutive-day streak. Existing workout history is used automatically—no extra setup.
